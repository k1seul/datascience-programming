# Week 04 / C (중간) — 연결 리스트를 재귀로

Week 01 에서 연결 리스트를 반복문으로 다뤘고, Week 03 에서 재귀를 배웠습니다.
이번에는 **둘을 합칩니다.** 같은 연결 리스트를, 이번에는 재귀로만 훑습니다.

연결 리스트는 구조 자체가 재귀적입니다. "노드 하나 + 나머지 리스트" 이니까요.
그래서 재귀가 아주 잘 맞습니다.

```
head -> [1] -> [2] -> [3] -> NULL
         ^      ^^^^^^^^^^^^^^^^^
         노드    나머지 리스트 (이것도 연결 리스트)
```

## 구현할 함수

`list.h` 에 선언되어 있습니다. **네 함수 모두 재귀로 작성해야 합니다.**

```c
int  sum_values(const Node *head);
int  max_value(const Node *head, int *out);
int  to_string_reverse(const Node *head, char *out, int out_capacity);
Node *drop_value(Node *head, int x);
```

| 함수 | 하는 일 | 반환값 |
|---|---|---|
| `sum_values` | 모든 값의 합. 빈 리스트는 `0` | 합 |
| `max_value` | 가장 큰 값을 `*out` 에 | `0`, 빈 리스트면 `-1` |
| `to_string_reverse` | 값을 **역순**으로 문자열에 | 쓴 글자 수, 용량 부족이면 `-1` |
| `drop_value` | 값이 `x` 인 노드를 모두 빼기 | 새 머리 |

## 조건

- **`for` 와 `while` 을 쓰지 마세요.** 채점기가 소스를 확인합니다.
- **`free` 를 호출하지 마세요.** 노드 메모리는 채점기가 만들고 관리합니다.
  `drop_value` 는 링크만 다시 이으면 됩니다.
- `to_string_reverse` 는 리스트를 바꾸지 않아야 합니다. 뒤집어서 읽기만 합니다.

## `to_string_reverse` 의 출력 형식

형식이 정확해야 합니다. 값마다 **뒤에 공백 하나**, 마지막 개행은 **없습니다**.

```
1 -> 2 -> 3   =>   "3 2 1 "     (6글자, 끝에 공백 있음)
1             =>   "1 "         (2글자)
빈 리스트      =>   ""           (0글자)
```

용량은 NUL 문자를 포함해 계산합니다. `"3 2 1 "` 은 6글자이므로 `out_capacity` 가
최소 7이어야 합니다.

## 힌트

`to_string_reverse` 가 이번 과제의 핵심입니다. 역순으로 쓰려면 **재귀를 먼저 부르고,
돌아온 다음에** 자기 값을 써야 합니다.

```c
/* 순서대로 쓰고 싶다면 */        /* 역순으로 쓰고 싶다면 */
자기 값을 쓴다;                   나머지를 먼저 처리한다;
나머지를 처리한다;                 자기 값을 쓴다;
```

이 순서 하나만 바꾸면 방향이 뒤집힙니다. 재귀의 "돌아오는 길"에서 일하는 것이죠.
`drop_value` 도 같은 발상입니다. 나머지 리스트를 먼저 처리해서 받은 결과를
자기 `next` 에 이어 붙이고, 자기 값이 `x` 면 자기를 건너뛴 결과를 반환합니다.
