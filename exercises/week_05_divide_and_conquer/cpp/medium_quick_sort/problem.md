# Week 05 / C++ (중간) — 퀵 소트

정수 배열을 오름차순으로 정렬합니다. 이번에는 **퀵 소트**를 직접 구현합니다.

Week 03 에서 머지 소트를 짰으니 시그니처가 같은 것을 눈치채셨을 겁니다. 일부러 그랬습니다.
**같은 일을 다른 방식으로** 해 보는 것이 이번 과제의 목적입니다.

```
[5, 2, 9, 1, 5, 6]  ->  [1, 2, 5, 5, 6, 9]
```

## 시그니처

```cpp
extern "C" int quick_sort(const int *values, int n, int *out, int out_capacity);
```

- 입력 `values` 는 바꾸지 마세요 (`const` 입니다). 결과는 `out` 에 씁니다.
- 반환값은 `out` 에 쓴 개수(`n`)입니다. `out_capacity` 가 `n` 보다 작으면 `-1` 입니다.
- `n >= 0` 이고, 빈 배열이면 아무것도 쓰지 않고 `0` 을 반환합니다.
- 중복된 값과 음수가 모두 들어옵니다.

## 조건

- **`std::sort`, `std::stable_sort`, `std::nth_element`, `std::partial_sort`, `qsort` 를
  쓰지 마세요.** 채점기가 소스를 확인합니다.
- 기준값(피벗)으로 **가르는 과정을 직접** 써야 합니다.

## 머지 소트와 무엇이 다른가

```
머지 소트:  일단 반으로 쪼갠다  ->  각각 정렬한다  ->  정렬된 둘을 합친다
                                                      ^^^^^^^^ 여기서 일한다

퀵 소트:    기준값으로 가른다  ->  각각 정렬한다  ->  끝. 합칠 일이 없다
            ^^^^^^^^ 여기서 일한다
```

머지 소트는 **돌아오는 길에** 일하고, 퀵 소트는 **들어가는 길에** 일합니다.
기준값보다 작은 것을 왼쪽, 큰 것을 오른쪽으로 몰아 두면 기준값의 자리는 이미 정해집니다.
그러면 왼쪽과 오른쪽을 따로 정렬하기만 하면 되고, 합치는 단계가 아예 없습니다.

| | 머지 소트 (Week 03) | 퀵 소트 (이번 주) |
|---|---|---|
| 일하는 시점 | 쪼갠 뒤 (합칠 때) | 쪼개기 전 (가를 때) |
| 추가 메모리 | 임시 버퍼가 필요 | 제자리에서 가능 |
| 최악의 경우 | 항상 `O(n log n)` | **`O(n²)`** |

마지막 줄이 이번 과제에서 꼭 알아야 할 내용입니다.

## 생각해 볼 것

- **이미 정렬된 배열에 첫 원소를 피벗으로 쓰면** 어떻게 될까요?
  가르고 나면 한쪽이 비고 다른 쪽에 `n-1` 개가 남습니다. 매번 1개씩만 떼어 내는 셈이죠.
  재귀 깊이가 얼마가 되고, `n` 이 100만이면 무슨 일이 생길까요?
  (Week 03 머지 소트에서 질문으로만 남겼던 것이 여기서 실제로 벌어집니다.)
- 그래서 피벗을 어떻게 고르면 좋을까요? 가운데 원소, 무작위, 세 값의 중앙값 같은 방법이
  있습니다. 각각 어떤 입력에 약할까요?
- 모든 값이 같은 배열(`[7, 7, 7, 7]`)은 어떻게 갈라질까요? 이것도 최악의 경우에 해당합니다.
- 퀵 소트는 제자리 정렬이 가능한데, 이 과제는 왜 결과를 `out` 에 쓰게 할까요?
  입력이 `const` 인 것과 관계가 있습니다.
- 머지 소트와 퀵 소트 중 **안정 정렬(stable)** 인 것은 어느 쪽인가요?
  정수만 다룰 때는 차이가 안 보이지만, 값에 딸린 정보가 있으면 달라집니다.
