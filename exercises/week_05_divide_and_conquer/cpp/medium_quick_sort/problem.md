# Week 05 / C++ (중간) — 퀵 소트

정수 배열을 오름차순으로 정렬하는 함수를 **퀵 소트**로 작성하세요.

## 문제

정수 배열 `values` 와 그 길이 `n` 이 주어집니다. 이 원소들을 오름차순으로 정렬해서 `out` 에 쓰고,
쓴 개수를 반환하세요.

- `values` 는 **수정하면 안 됩니다** (`const`). 먼저 `out` 에 복사한 다음 `out` 을 정렬하면 됩니다.
- `out` 에는 최대 `out_capacity` 개까지 쓸 수 있습니다. `out_capacity` 가 `n` 보다 작으면
  아무것도 쓰지 말고 `-1` 을 반환하세요.
- 빈 배열(`n = 0`)이면 `0` 을 반환하세요.
- 음수와 중복된 값이 들어올 수 있습니다.

## 예시

| `values` | `out_capacity` | `out` 에 쓰이는 값 | 반환값 |
|---|---|---|---|
| `[5, 2, 9, 1, 5, 6]` | `6` 이상 | `[1, 2, 5, 5, 6, 9]` | `6` |
| `[0, -1, 3, -2]` | `4` 이상 | `[-2, -1, 0, 3]` | `4` |
| `[7, 7, 7]` | `3` 이상 | `[7, 7, 7]` | `3` |
| `[]` | 아무 값 | (없음) | `0` |
| `[3, 1, 2]` | `2` | (쓰지 않음) | `-1` |

## 구현할 함수

`solution.cpp` 에 작성하세요.

```cpp
extern "C" int quick_sort(const int *values, int n, int *out, int out_capacity);
```

함수 이름 앞의 `extern "C"` 는 지우지 마세요. 채점기가 이 함수를 찾을 때 필요합니다.
같은 파일 안에 보조 함수를 얼마든지 만들어도 됩니다.

## 퀵 소트는 어떻게 동작하나요

세 단계를 반복합니다.

1. 배열에서 원소 하나를 **기준값(피벗, pivot)** 으로 고릅니다.
2. 기준값보다 **작은 원소는 왼쪽, 나머지는 오른쪽**으로 옮깁니다. 이 과정을 **분할(partition)** 이라고 합니다.
   분할이 끝나면 기준값은 정렬된 결과에서 자기가 있어야 할 자리에 놓입니다.
3. 기준값의 왼쪽 부분과 오른쪽 부분을 **각각 같은 방법으로** 정렬합니다 (재귀).

원소가 하나 이하인 부분은 이미 정렬된 것이니 더 나누지 않습니다.

```
[5  2  9  1  6]          기준값으로 5를 고른다
[2  1] 5 [9  6]          5보다 작은 2, 1은 왼쪽 / 큰 9, 6은 오른쪽
                         이제 5는 제자리다. 왼쪽과 오른쪽만 정렬하면 된다

[2  1]  ->  [1] 2        기준값 2로 다시 나눈다
[9  6]  ->  [6] 9        기준값 9로 다시 나눈다

[1  2  5  6  9]          완성
```

## 힌트

막힐 때 하나씩 펼쳐 보세요.

<details>
<summary>힌트 1 — 함수를 어떻게 나누면 좋을까요?</summary>

`quick_sort` 안에서 직접 재귀하려면 범위를 넘길 방법이 없습니다. 보조 함수를 하나 만드세요.

```cpp
static void sort_range(int *a, int lo, int hi);   // a[lo] ~ a[hi-1] 을 정렬
```

`quick_sort` 는 `values` 를 `out` 에 복사한 다음 `sort_range(out, 0, n)` 을 부르기만 하면 됩니다.

</details>

<details>
<summary>힌트 2 — 분할(partition)은 어떻게 쓰나요?</summary>

가장 이해하기 쉬운 방법 하나를 소개합니다.

1. 기준값을 배열의 **맨 끝**으로 옮겨 둡니다.
2. 변수 `i` 를 `lo` 로 둡니다. `i` 는 "기준값보다 작은 원소를 다음에 놓을 자리"입니다.
3. `lo` 부터 맨 끝 바로 앞까지 차례로 보면서, 기준값보다 작은 원소를 만나면 `a[i]` 와 바꾸고 `i` 를 1 늘립니다.
4. 다 보고 나면 맨 끝의 기준값을 `a[i]` 와 바꿉니다. 이제 기준값은 인덱스 `i` 에 있습니다.

```cpp
int pivot = a[hi - 1];
int i = lo;
for (int j = lo; j < hi - 1; j++) {
    if (a[j] < pivot) {
        // a[i] 와 a[j] 를 바꾸고 i++
    }
}
// a[i] 와 a[hi - 1] 을 바꾼다
// 이제 기준값은 a[i] 에 있다
```

그다음 `sort_range(a, lo, i)` 와 `sort_range(a, i + 1, hi)` 를 부르면 됩니다.

</details>

<details>
<summary>힌트 3 — 기준값은 무엇으로 고르나요?</summary>

**가운데 원소**를 고르는 것을 권합니다. 힌트 2의 방법을 쓰려면 가운데 원소를 먼저 맨 끝 원소와
바꿔 두면 됩니다.

```cpp
int mid = lo + (hi - lo) / 2;
// a[mid] 와 a[hi - 1] 을 바꾼다
```

맨 앞이나 맨 끝 원소를 그대로 기준값으로 쓰면, 이미 정렬된 배열이 들어왔을 때 아주 느려집니다.
아래 "자주 하는 실수"를 보세요.

</details>

## 자주 하는 실수

**재귀할 때 기준값까지 포함하기**

분할 뒤에는 기준값을 **빼고** 양쪽을 재귀해야 합니다. `sort_range(a, lo, i + 1)` 처럼 기준값을
포함하면, 기준값이 가장 큰 경우 범위가 줄지 않아서 재귀가 끝나지 않습니다.

**이미 정렬된 배열에 맨 끝(또는 맨 앞) 원소를 기준값으로 쓰기**

`[1, 2, 3, 4, 5]` 에서 맨 끝의 `5` 를 기준값으로 쓰면 나머지가 전부 왼쪽으로 갑니다.
한 번에 원소 하나만 줄어드는 셈이라 재귀가 `n` 번 깊어지고, 시간도 `O(n²)` 이 됩니다.
`n` 이 크면 스택이 넘쳐서 프로그램이 그냥 죽습니다. 기준값을 가운데에서 고르면 피할 수 있습니다.

**입력 배열을 정렬하기**

`values` 는 `const` 입니다. `out` 에 복사한 다음 `out` 을 정렬하세요.

## 참고 — Week 03 머지 소트와 비교

두 정렬은 모두 배열을 나눠서 푸는 분할 정복이지만, 일하는 시점이 다릅니다.

| | 머지 소트 (Week 03) | 퀵 소트 (이번 주) |
|---|---|---|
| 하는 일 | 반으로 나눠 각각 정렬한 뒤 **합친다** | 기준값으로 **나눈 뒤** 각각 정렬한다 |
| 추가 메모리 | 합칠 때 임시 배열이 필요 | 배열 안에서 자리만 바꾸면 된다 |
| 가장 느린 경우 | 항상 `O(n log n)` | 기준값을 잘못 고르면 `O(n²)` |
