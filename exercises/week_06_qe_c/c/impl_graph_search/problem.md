# Week 06 / C (구현) — 그래프 탐색

방향 그래프를 **인접 리스트**로 만들고, 그 위에서 **BFS**, **DFS**, **사이클 판정**을 구현합니다.

| 소문항 | 함수 | 하는 일 | 배점 |
|---|---|---|---|
| (a) | `graph_create`, `graph_add_edge`, `graph_free` | 그래프 만들기, 간선 넣기, 해제하기 | 20 |
| (b) | `graph_print` | 인접 리스트 출력하기 | 10 |
| (c) | `graph_bfs_distance` | 시작점에서 각 정점까지 최단 거리 | 25 |
| (d) | `graph_dfs_order` | 깊이 우선으로 방문한 순서 | 20 |
| (e) | `graph_has_cycle` | 사이클이 있는지 | 25 |

## 구조체

`graph.h` 에 이미 정의되어 있습니다. **이 파일은 고치지 마세요.** 함수는 모두 `solution.c` 에 작성합니다.

```c
typedef struct Edge {
    int to;              /* 이 간선이 가리키는 정점 */
    struct Edge *next;   /* 같은 정점에서 나가는 다음 간선 */
} Edge;

typedef struct {
    int n;        /* 정점 수. 정점 번호는 0 ~ n-1 */
    Edge **adj;   /* adj[v]: 정점 v 에서 나가는 첫 간선. 없으면 NULL */
} Graph;
```

정점마다 **나가는 간선을 연결 리스트로** 들고 있습니다. `adj` 는 그 리스트의 첫 노드를 가리키는 포인터 `n` 개짜리 배열입니다.

이 문서에서는 아래 그래프를 계속 예로 씁니다. **그래프 G** 라고 부르겠습니다.

```
그래프 G                         인접 리스트

  0 --> 1 --> 3 --> 4            adj[0] -> [1] -> [2] -> NULL
  |           ^                  adj[1] -> [3] -> NULL
  +---> 2 ----+                  adj[2] -> [3] -> NULL
                                 adj[3] -> [4] -> NULL
  5  (간선 없음)                  adj[4] -> NULL
                                 adj[5] -> NULL
```

간선은 `(0,1)`, `(0,2)`, `(1,3)`, `(2,3)`, `(3,4)` 순서로 넣었습니다. **방향이 있어서** 3 에서 1 로는 갈 수 없습니다.

## (a) `graph_create`, `graph_add_edge`, `graph_free` — 20점

```c
Graph *graph_create(int n);
int graph_add_edge(Graph *g, int from, int to);
void graph_free(Graph *g);
```

- `graph_create` 는 정점 `n` 개, 간선 0개인 그래프를 만듭니다. `adj` 를 `n` 칸 할당하고 **모두 `NULL`** 로 둡니다.
  `n` 이 1 보다 작으면 `NULL` 을 반환합니다.
- `graph_add_edge` 는 간선 `from → to` 를 `adj[from]` 리스트의 **맨 뒤에** 붙이고 `1` 을 반환합니다.
  - `from` 이나 `to` 가 `0 ~ n-1` 이 아니면 아무것도 하지 않고 `0` 을 반환합니다.
  - 자기 자신으로 가는 간선(`from == to`)도 넣습니다. 같은 간선을 또 넣으면 또 붙습니다.
- `graph_free` 는 모든 간선, `adj` 배열, 그래프 자체를 해제합니다. `NULL` 을 받으면 아무것도 하지 않습니다.

**맨 뒤에 붙이는 것이 중요합니다.** 리스트 순서가 곧 (b)에서 출력하는 순서이고, (d)에서 이웃을 방문하는 순서입니다.

## (b) `graph_print` — 10점

```c
void graph_print(const Graph *g);
```

정점 `0` 부터 한 줄에 하나씩, `정점:` 다음에 이웃을 **리스트 순서대로** 공백 하나씩 띄워 출력합니다.
채점기가 **글자 하나까지** 비교합니다. 그래프 G 는 이렇게 출력됩니다.

```
0: 1 2
1: 3
2: 3
3: 4
4:
5:
```

이웃이 없는 정점은 `4:` 처럼 콜론 뒤에 아무것도 없습니다 (공백도 없습니다).

## (c) `graph_bfs_distance` — 25점

```c
int graph_bfs_distance(const Graph *g, int start, int *dist);
```

`start` 에서 각 정점까지 **간선을 가장 적게 거치는 경로의 간선 수**를 `dist` 에 씁니다.

- `dist` 에는 `n` 칸이 있습니다. `dist[start]` 는 `0` 이고, 갈 수 없는 정점은 `-1` 입니다.
- 반환값은 `start` 에서 갈 수 있는 정점 수입니다 (`start` 자신도 셉니다).
- `start` 가 `0 ~ n-1` 이 아니면 `dist` 를 건드리지 말고 `-1` 을 반환합니다.

그래프 G 에서 해 보면 이렇습니다.

| `start` | `dist` | 반환값 |
|---|---|---|
| `0` | `[0, 1, 1, 2, 3, -1]` | `5` |
| `3` | `[-1, -1, -1, 0, 1, -1]` | `2` |
| `5` | `[-1, -1, -1, -1, -1, 0]` | `1` |

`start = 0` 일 때 3 까지는 `0 → 1 → 3` 과 `0 → 2 → 3` 두 길이 있고, 둘 다 간선 2개라 `dist[3] = 2` 입니다.

**BFS(너비 우선 탐색)** 로 구하세요. 시작점에서 가까운 정점부터 차례로 방문하는 방법입니다.

1. 모든 `dist` 를 `-1` 로 두고, `dist[start] = 0` 으로 정한 뒤 `start` 를 큐에 넣습니다.
2. 큐에서 정점 `v` 를 꺼내고, `v` 의 이웃 중 `dist` 가 아직 `-1` 인 정점 `w` 마다
   `dist[w] = dist[v] + 1` 로 정하고 `w` 를 큐에 넣습니다.
3. 큐가 빌 때까지 2를 반복합니다.

큐는 함수 안에서 직접 만들고, 반환하기 전에 해제하세요.

## (d) `graph_dfs_order` — 20점

```c
int graph_dfs_order(const Graph *g, int start, int *order);
```

`start` 에서 **DFS(깊이 우선 탐색)** 를 하면서 정점을 **처음 방문한 순서대로** `order` 에 씁니다.
방문한 정점 수를 반환합니다. `start` 가 `0 ~ n-1` 이 아니면 `-1` 을 반환합니다.

DFS 의 규칙은 이렇습니다.

1. 정점을 방문하면 `order` 에 적고 방문했다고 표시합니다.
2. 그 정점의 이웃을 **리스트 순서대로** 보면서, 아직 방문하지 않은 이웃이 있으면 **그 이웃으로 들어가서 끝까지 탐색한 다음** 돌아와 다음 이웃을 봅니다.

그래프 G 에서 `start = 0` 이면 이렇게 진행됩니다.

| 차례 | 지금 정점 | 하는 일 | `order` |
|---|---|---|---|
| 1 | 0 | 방문. 이웃 1, 2 중 1 로 들어간다 | `0` |
| 2 | 1 | 방문. 이웃 3 으로 들어간다 | `0 1` |
| 3 | 3 | 방문. 이웃 4 로 들어간다 | `0 1 3` |
| 4 | 4 | 방문. 이웃이 없으니 3 으로 돌아간다 | `0 1 3 4` |
| 5 | 3 → 1 → 0 | 더 볼 이웃이 없어서 0 까지 돌아온다. 0 의 다음 이웃 2 로 들어간다 | |
| 6 | 2 | 방문. 이웃 3 은 이미 방문했다. 끝 | `0 1 3 4 2` |

반환값은 `5` 입니다. 같은 그래프에서 BFS 로 방문하면 `0 1 2 3 4` 순서가 되니 둘이 다르다는 것을 확인해 보세요.

| 그래프 | `start` | `order` |
|---|---|---|
| G | `2` | `[2, 3, 4]` |
| G 에서 `(0,2)` 를 `(0,1)` 보다 먼저 넣은 그래프 | `0` | `[0, 2, 3, 4, 1]` |
| `0→1`, `1→2`, `2→0` | `1` | `[1, 2, 0]` |

**재귀로 쓰는 것을 권합니다.** 위 규칙을 그대로 옮기면 재귀 함수가 됩니다.

## (e) `graph_has_cycle` — 25점

```c
int graph_has_cycle(const Graph *g);
```

그래프 어딘가에 **사이클**(간선을 따라가서 출발한 정점으로 돌아오는 길)이 있으면 `1`, 없으면 `0` 을 반환합니다.
자기 자신으로 가는 간선 하나도 사이클입니다.

| 그래프 | 결과 | |
|---|---|---|
| G | `0` | |
| `0→1`, `1→2`, `2→0` | `1` | 0 → 1 → 2 → 0 |
| `0→0` | `1` | 자기 자신으로 가는 간선 |
| `0→1`, `0→2`, `1→3`, `2→3` | **`0`** | 3 을 두 번 만나지만 돌아오는 길은 없습니다 |
| `0→1`, `2→3`, `3→2` | `1` | 0 에서는 갈 수 없는 곳에 사이클이 있습니다 |

DFS 를 하면서 정점마다 상태를 **세 가지**로 기록하면 됩니다.

| 상태 | 뜻 |
|---|---|
| 아직 안 감 | 한 번도 방문하지 않았습니다 |
| **탐색 중** | 방문했고, 그 정점에서 들어간 탐색이 아직 끝나지 않았습니다 (재귀가 아직 돌아오지 않았습니다) |
| 끝남 | 그 정점에서 갈 수 있는 곳을 다 보고 돌아왔습니다 |

**"탐색 중"인 정점으로 가는 간선을 만나면 사이클입니다.** 지금 따라온 길 위의 정점으로 되돌아가는 것이기 때문입니다.
"끝남"인 정점으로 가는 간선은 사이클이 아닙니다. 위 표의 네 번째 그래프가 그런 경우입니다.

<details>
<summary>힌트 1 — graph_create 와 graph_add_edge</summary>

`adj` 를 모두 `NULL` 로 채우려면 `calloc` 이 편합니다. 할당하면서 0 으로 채워 줍니다.

```c
g->adj = calloc(n, sizeof(Edge *));
```

`graph_add_edge` 에서 맨 뒤에 붙이려면 리스트의 마지막 간선까지 따라가야 합니다.
리스트가 비어 있으면(`adj[from] == NULL`) 따라갈 간선이 없으니 `adj[from]` 에 바로 넣습니다.

</details>

<details>
<summary>힌트 2 — BFS 의 큐는 배열 하나로 충분합니다</summary>

정점은 큐에 **한 번씩만** 들어갑니다 (`dist` 가 `-1` 일 때만 넣으니까요). 그래서 `n` 칸 배열과
인덱스 두 개면 원형으로 돌릴 필요도 없습니다.

```c
int *queue = malloc(sizeof(int) * g->n);
int head = 0, tail = 0;
queue[tail++] = start;          /* 넣기 */
while (head < tail) {
    int v = queue[head++];      /* 꺼내기 */
    /* v 의 이웃을 본다 */
}
free(queue);
```

끝났을 때 `tail` 은 큐에 들어갔던 정점 수, 곧 갈 수 있는 정점 수입니다.
1번 과제의 덱을 복사해 와서 써도 됩니다.

</details>

<details>
<summary>힌트 3 — DFS 재귀 함수의 모양</summary>

방문 표시 배열과, `order` 에 몇 개 썼는지를 재귀 호출끼리 함께 써야 합니다. 보조 함수에 포인터로 넘기세요.

```c
static void dfs_visit(const Graph *g, int v, int *visited, int *order, int *count)
{
    visited[v] = 1;
    order[(*count)++] = v;
    /* v 의 이웃 중 visited 가 0 인 것마다 dfs_visit(...) */
}
```

`graph_dfs_order` 는 `visited` 를 `calloc` 하고, `dfs_visit` 을 한 번 부르고, `visited` 를 해제하면 됩니다.

</details>

<details>
<summary>힌트 4 — has_cycle 은 모든 정점에서 출발해 봅니다</summary>

```c
static int dfs_cycle(const Graph *g, int v, int *state)
{
    state[v] = 1;                       /* 탐색 중 */
    /* 이웃 w 마다:
     *     state[w] == 1 이면 사이클 -> 1 반환
     *     state[w] == 0 이면 dfs_cycle(g, w, state) 가 1 이면 1 반환 */
    state[v] = 2;                       /* 끝남 */
    return 0;
}
```

`graph_has_cycle` 에서는 `state` 가 `0` 인 정점 **모두**에서 `dfs_cycle` 을 불러 봅니다.
0 번 정점에서만 출발하면 0 에서 갈 수 없는 곳의 사이클을 놓칩니다.

</details>

## 자주 하는 실수

**간선을 리스트 맨 앞에 붙이기**

맨 앞에 붙이는 쪽이 코드가 짧아서 많이 씁니다. 그런데 그러면 리스트 순서가 넣은 순서와 반대가 되어서
(b)의 출력과 (d)의 방문 순서가 달라집니다.

**BFS 에서 꺼낼 때 방문 표시하기**

큐에 **넣을 때** `dist` 를 정해야 합니다. 꺼낼 때 정하면 그 사이에 같은 정점이 큐에 여러 번 들어가서
`n` 칸짜리 큐가 넘칠 수 있습니다. 배열 밖에 쓰게 되니 프로그램이 그냥 죽기도 합니다.

**사이클 판정에서 "방문했다" 하나만 기록하기**

두 상태(방문함 / 안 함)만 쓰면 `0→1`, `0→2`, `1→3`, `2→3` 에서 3 을 두 번째 만날 때 사이클이라고 잘못 판정합니다.
"탐색 중"과 "끝남"을 구분해야 합니다.

**`graph_free` 에서 `adj` 만 해제하기**

`adj` 는 리스트의 **첫 노드를 가리키는 포인터** 배열일 뿐입니다. 각 리스트의 간선 노드를 먼저 모두 해제해야 합니다.
