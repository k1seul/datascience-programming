# Week 02 / C++ (쉬움) — 두 배열의 교집합

두 정수 배열이 주어집니다. 양쪽에 모두 나오는 값들을 찾아 주세요.

```
a = [1, 2, 2, 1],  b = [2, 2]        ->  [2]
a = [4, 9, 5],     b = [9, 4, 9, 8]  ->  [4, 9]
a = [1, 2, 3],     b = [4, 5]        ->  []
```

## 시그니처

```cpp
extern "C" int intersection(const int *a, int na, const int *b, int nb,
                            int *out, int out_capacity);
```

- 반환값은 `out` 에 쓴 개수입니다. 용량이 부족하면 아무것도 쓰지 않고 `-1` 입니다.
- **같은 값은 한 번만** 넣습니다. 위 첫 번째 예에서 `2` 가 네 번 나오지만 결과는 `[2]` 하나입니다.
- **순서는 상관없습니다.** 채점기가 정렬해서 비교합니다.

## 조건

- `std::unordered_set` 으로 풀어 주세요. 한쪽 배열을 집합에 넣고 다른 쪽을 훑으면 됩니다.
- 값은 음수일 수도 있고 범위 제한이 없습니다. 그래서 C 과제처럼 `seen[value]` 배열을 쓸 수 없습니다.
  이번 주에 해시가 왜 필요한지 보여 주는 부분입니다.
- 정렬한 뒤 두 포인터로 훑어도 답은 나오지만, 이번 주 주제는 해싱이니 집합으로 풀어 주세요.
