# Week 02 / C++ (중간) — 합이 k 인 부분 배열 개수

정수 배열에서 **연속한 구간**의 합이 `k` 가 되는 경우가 몇 개인지 세어 주세요.

```
[1, 1, 1],        k = 2   ->  2     ([1,1] 이 두 군데)
[1, 2, 3],        k = 3   ->  2     ([1,2] 와 [3])
[1, -1, 0],       k = 0   ->  3     ([1,-1], [0], [1,-1,0])
```

## 시그니처

```cpp
extern "C" int subarray_sum(const int *values, int n, int k);
```

- 반환값은 조건을 만족하는 구간의 개수입니다.
- 길이가 1 인 구간도 셉니다. 길이 0 인 빈 구간은 세지 않습니다.
- `n >= 0` 이고, 빈 배열이면 `0` 입니다.

## 조건

- **`O(n)` 으로 풀어 주세요.** 모든 구간을 이중 반복문으로 확인하면 `O(n²)` 이고,
  채점기가 큰 입력을 주기 때문에 시간 안에 끝나지 않습니다.
- 값에 **음수가 섞여 있습니다.** 그래서 슬라이딩 윈도우로는 풀리지 않습니다.
  구간 합을 넓히다가 줄이는 전략이 통하려면 값이 모두 양수여야 하니까요.

## 핵심 아이디어

`prefix[i]` 를 "앞에서부터 i 개를 더한 값" 이라고 하면, 구간 `(j, i]` 의 합은
`prefix[i] - prefix[j]` 입니다. 이 값이 `k` 가 되려면

```
prefix[i] - prefix[j] = k
prefix[j] = prefix[i] - k
```

즉 **지금까지 지나온 prefix 값들 중에 `prefix[i] - k` 가 몇 번 나왔는지**를 알면 됩니다.
그 개수를 세는 것이 이번 주의 해시 맵(`std::unordered_map<long long, int>`)입니다.

시작할 때 `prefix = 0` 을 한 번 넣어 두어야 배열 맨 앞부터 시작하는 구간이 세어집니다.
