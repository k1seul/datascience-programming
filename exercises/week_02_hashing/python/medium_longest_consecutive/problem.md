# Week 02 / Python (중간) — 가장 긴 연속 수열

정수 배열에서 **연속된 수**가 가장 길게 이어지는 구간의 길이를 찾습니다.
배열에서의 위치는 상관없고 값만 이어지면 됩니다.

```
[100, 4, 200, 1, 3, 2]          ->  4    (1, 2, 3, 4)
[0, 3, 7, 2, 5, 8, 4, 6, 0, 1]  ->  9    (0 부터 8 까지)
[]                              ->  0
```

## 구현할 함수

```python
def longest_consecutive(values: Sequence[int]) -> int: ...
def longest_consecutive_range(values: Sequence[int]) -> tuple[int, int] | None: ...
```

- `longest_consecutive` 는 길이를, `longest_consecutive_range` 는 `(시작값, 끝값)` 을 반환합니다.
- 가장 긴 구간이 여럿이면 **시작값이 가장 작은** 것을 고릅니다.
- 빈 입력이면 각각 `0` 과 `None` 입니다.
- 중복된 값은 한 번으로 셉니다. `[1, 1, 2]` 의 답은 `2` 입니다.

## 조건

- **`O(n)` 으로 풀어 주세요.** 정렬하면 `O(n log n)` 이고, 이번 주 주제에서 벗어납니다.
  채점기가 `sorted` 사용을 확인합니다.
- 집합(`set`)을 만들어 두고 **각 수가 구간의 시작인지**를 판정하는 것이 핵심입니다.
  `value - 1` 이 집합에 없으면 `value` 가 시작점입니다.
- 시작점에서만 위로 세어 올라가면, 전체를 통틀어 각 수를 한 번씩만 방문하게 됩니다.
  시작점인지 확인하지 않고 모든 수에서 세면 `O(n²)` 이 됩니다.
