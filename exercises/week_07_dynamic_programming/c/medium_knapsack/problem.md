# Week 07 / C (중간) — 광고 예산 나누기

광고 캠페인 후보가 `n` 개 있습니다. `i` 번 캠페인을 하려면 비용이 `cost[i]` 만큼 들고,
신규 가입자를 `value[i]` 명 데려올 것으로 예상됩니다.
**예산 `budget` 안에서 가입자를 가장 많이 데려오는 캠페인 조합**을 고르세요.

캠페인은 **하거나 안 하거나** 둘 중 하나입니다. 절반만 하거나 같은 캠페인을 두 번 할 수는 없습니다.
이런 문제를 **0/1 배낭 문제(0/1 knapsack)** 라고 부릅니다.

## 예시

| 번호 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 비용 | 1 | 3 | 4 | 5 |
| 효과 | 1 | 4 | 5 | 7 |

예산이 `7` 이면 답은 `9` 입니다. **1번과 2번**을 하면 비용 `3 + 4 = 7`, 효과 `4 + 5 = 9` 입니다.

| 고른 캠페인 | 비용 합 | 효과 합 | |
|---|---|---|---|
| 1번, 2번 | 7 | **9** | 가장 큼 |
| 0번, 3번 | 6 | 8 | |
| 3번 | 5 | 7 | |
| 2번, 3번 | 9 | | 예산을 넘습니다 |

**좋아 보이는 것부터 고르는 방법은 통하지 않습니다.** 비용 `[5, 4, 3]`, 효과 `[11, 7, 6]`, 예산 `7` 을 보세요.

- 비용 대비 효과가 가장 좋은 0번(5를 내고 11)을 먼저 고르면, 남은 예산 2로는 아무것도 못 해서 `11` 입니다.
- 1번과 2번을 고르면 비용 `7`, 효과 `13` 으로 더 많습니다.

그래서 이 문제는 가능한 경우를 빠짐없이, 하지만 빠르게 따져 보는 DP 로 풉니다.

## 구현할 함수

`knapsack.h` 에 선언되어 있습니다. **이 파일은 고치지 마세요.** 함수는 `solution.c` 에 작성합니다.

```c
int knapsack_best(const int *cost, const int *value, int n, int budget);
int knapsack_choose(const int *cost, const int *value, int n, int budget, int *chosen);
```

**(a) `knapsack_best`** 는 얻을 수 있는 가장 큰 효과 합을 반환합니다.

**(b) `knapsack_choose`** 는 같은 문제를 풀고, **실제로 고른 캠페인 번호**를 `chosen` 에 **오름차순**으로 적은 뒤
몇 개를 골랐는지 반환합니다.

```c
int cost[]  = {1, 3, 4, 5};
int value[] = {1, 4, 5, 7};
int chosen[4];

knapsack_best(cost, value, 4, 7);              /* 9 */
knapsack_choose(cost, value, 4, 7, chosen);    /* 2, chosen = {1, 2} */
```

- 효과가 가장 큰 조합이 여럿이면 **아무거나** 하나 적으면 됩니다. 채점기는 고른 조합을 직접 확인합니다.
  번호가 겹치지 않고 오름차순인지, 비용 합이 예산 이하인지, 효과 합이 가장 큰 값과 같은지 봅니다.
- `chosen` 에는 `n` 칸이 있습니다.

## 입력 조건

- `cost[i]` 는 1 이상, `value[i]` 는 0 이상입니다.
- `n` 은 100 이하, `budget` 은 10000 이하입니다.
- `n` 이나 `budget` 이 음수이면 두 함수 모두 `-1` 을 반환합니다.
- `n = 0` 이거나 아무것도 예산 안에 들어가지 않으면 효과는 `0`, 고른 개수도 `0` 입니다.

## 지켜야 할 것

- **표는 `malloc` 으로 만들고, 반환하기 전에 `free` 하세요.** 채점기가 Week 06 처럼 `malloc` 과 `free` 횟수를 세어서,
  함수가 끝난 뒤 해제하지 않은 메모리가 남으면 실패로 처리합니다.
- **캠페인 40개짜리 입력도 2초 안에 끝나야 합니다.** 모든 조합을 하나씩 해 보면 2⁴⁰ 가지(약 1조)라서 끝나지 않습니다.
- `knapsack.h` 는 고치지 마세요.

## 힌트

막힐 때 하나씩 펼쳐 보세요.

<details>
<summary>힌트 1 — 표의 한 칸이 뜻하는 것</summary>

`dp[i][b]` 를 "**앞의 `i` 개 캠페인만** 놓고 고를 때, **예산이 `b`** 이면 얻을 수 있는 가장 큰 효과"라고 합시다.

- 표의 크기는 `(n + 1) × (budget + 1)` 입니다. 캠페인 0개, 예산 0 인 경우도 있어야 하기 때문입니다.
- 첫 줄 `dp[0][b]` 는 모두 `0` 입니다. 고를 캠페인이 없으니까요.
- 답은 `dp[n][budget]` 입니다.

</details>

<details>
<summary>힌트 2 — i 번째 캠페인을 할까, 말까</summary>

`dp[i][b]` 를 채울 때는 `i` 번째 캠페인(번호로는 `i - 1`)을 **할지 말지** 두 경우만 보면 됩니다.

- **안 하면**: 앞의 `i - 1` 개로 예산 `b` 를 그대로 씁니다. → `dp[i-1][b]`
- **하면** (`cost[i-1] <= b` 일 때만): 그 비용을 빼고 남은 예산으로 앞의 `i - 1` 개를 고릅니다. → `dp[i-1][b - cost[i-1]] + value[i-1]`

둘 중 큰 값이 `dp[i][b]` 입니다.

예시(비용 `[1, 3, 4, 5]`, 효과 `[1, 4, 5, 7]`, 예산 `7`)로 채운 표입니다.

```
예산 b →                 0  1  2  3  4  5  6  7
캠페인 없음               0  0  0  0  0  0  0  0
+ 0번 (비용 1, 효과 1)    0  1  1  1  1  1  1  1
+ 1번 (비용 3, 효과 4)    0  1  1  4  5  5  5  5
+ 2번 (비용 4, 효과 5)    0  1  1  4  5  6  6  9
+ 3번 (비용 5, 효과 7)    0  1  1  4  5  7  8  9     ← 답은 맨 오른쪽 아래의 9
```

</details>

<details>
<summary>힌트 3 — 2차원 표를 malloc 하기</summary>

`(n + 1) × (budget + 1)` 칸을 한 줄로 이어서 1차원 배열 하나로 만들면 `malloc` 과 `free` 를 한 번씩만 하면 됩니다.

```c
int width = budget + 1;
int *dp = calloc((size_t)(n + 1) * width, sizeof(int));   /* 0 으로 채워진 표 */

dp[i * width + b]      /* dp[i][b] */
```

`calloc` 은 `malloc` 과 같지만 모든 칸을 0 으로 채워 줍니다. 해제는 똑같이 `free(dp)` 입니다.

</details>

<details>
<summary>힌트 4 — 무엇을 골랐는지 되짚기</summary>

표를 다 채운 뒤 **맨 아래 줄 오른쪽 끝**(`dp[n][budget]`)에서 시작해 위로 올라갑니다.

- `dp[i][b]` 와 바로 위 칸 `dp[i-1][b]` 가 **같으면** `i - 1` 번 캠페인은 안 해도 같은 값이 나옵니다. 그냥 위로 올라갑니다.
- **다르면** `i - 1` 번 캠페인을 했기 때문에 값이 커진 것입니다. 번호를 적고, 예산에서 그 비용을 빼고(`b -= cost[i-1]`) 위로 올라갑니다.

힌트 2의 표로 따라가면 이렇습니다.

| 위치 | 위 칸과 비교 | 결정 |
|---|---|---|
| `dp[4][7] = 9` | `dp[3][7] = 9` 와 같음 | 3번 안 함 |
| `dp[3][7] = 9` | `dp[2][7] = 5` 와 다름 | 2번 함, `b = 7 - 4 = 3` |
| `dp[2][3] = 4` | `dp[1][3] = 1` 과 다름 | 1번 함, `b = 3 - 3 = 0` |
| `dp[1][0] = 0` | `dp[0][0] = 0` 과 같음 | 0번 안 함 |

뒤에서부터 찾았으니 `{2, 1}` 순서로 나옵니다. 오름차순으로 뒤집어서 `{1, 2}` 를 돌려주세요.

</details>

## 자주 하는 실수

**표를 한 칸씩 작게 만들기**

`n × budget` 으로 만들면 `dp[n][budget]` 이 표 밖입니다. 두 쪽 다 `+ 1` 입니다.

**1차원 인덱스의 폭을 틀리기**

한 줄의 길이는 `budget` 이 아니라 `budget + 1` 입니다. `dp[i * budget + b]` 로 쓰면 줄끼리 겹칩니다.

**일찍 `return` 하면서 `free` 를 빠뜨리기**

함수 중간에 `return` 하는 곳이 있다면, 그 앞에도 `free(dp)` 가 있어야 합니다.

**되짚은 번호를 뒤집지 않기**

뒤에서부터 찾으면 내림차순으로 나옵니다. 채점기는 오름차순만 받습니다.
