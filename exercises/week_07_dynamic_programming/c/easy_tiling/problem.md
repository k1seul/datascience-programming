# Week 07 / C (쉬움) — 타일 채우기

세로 2칸, 가로 `n` 칸인 판을 **1×2 타일**로 빈틈없이 채우려고 합니다.
타일은 세로로 세워도 되고 가로로 눕혀도 됩니다. 채우는 방법은 모두 몇 가지일까요?

아래 그림에서 **같은 글자가 타일 하나**입니다.

```
n = 1 (1가지)     n = 2 (2가지)      n = 3 (3가지)

    A              AB   AA          ABC   ABB   AAC
    A              AB   BB          ABC   ACC   BBC
```

`n = 3` 의 세 가지는 "세로 세 개", "세로 하나 + 가로 두 개", "가로 두 개 + 세로 하나"입니다.

## 문제

**(a)** 1×2 타일만 쓸 때 채우는 방법의 수를 구하세요.

**(b)** 이번에는 **2×2 타일**도 쓸 수 있습니다. 채우는 방법의 수를 구하세요.

```
n = 2 일 때 (b) 는 3가지

AB   AA   AA
AB   BB   AA      ← 세 번째는 2×2 타일 하나
```

| `n` | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 10 |
|---|---|---|---|---|---|---|---|---|
| (a) `tiling(n)` | 1 | 1 | 2 | 3 | 5 | 8 | 13 | 89 |
| (b) `tiling_with_square(n)` | 1 | 1 | 3 | 5 | 11 | 21 | 43 | 683 |

`n = 0` 은 빈 판입니다. **아무것도 놓지 않는 한 가지**가 있으니 답은 `1` 입니다.

## 구현할 함수

`tiling.h` 에 선언되어 있습니다. **이 파일은 고치지 마세요.** 함수는 `solution.c` 에 작성합니다.

```c
long long tiling(int n);
long long tiling_with_square(int n);
```

| 함수 | 받는 `n` | 범위 밖이면 |
|---|---|---|
| `tiling` | 0 ~ 90 | `-1` |
| `tiling_with_square` | 0 ~ 60 | `-1` |

**반환형이 `long long` 입니다.** 값이 금방 커져서 `tiling(46)` 부터는 `int` 에 담기지 않습니다.
계산하는 중간 값도 `long long` 으로 두세요. `tiling(90)` 은 `4660046610375530309` 입니다.

## 지켜야 할 것

- **큰 `n` 은 2초 안에 끝나야 합니다.** 채점기가 `tiling(90)` 과 `tiling_with_square(60)` 을 부릅니다.
  재귀로만 풀면 `tiling(50)` 도 끝나지 않습니다. 배열에 작은 `n` 부터 채우세요.
- `tiling.h` 는 고치지 마세요.

## 힌트

<details>
<summary>힌트 1 — 맨 오른쪽 칸만 보세요</summary>

판의 **맨 오른쪽 열**이 어떻게 채워지는지는 두 가지뿐입니다.

```
....X          ...YY
....X          ...ZZ

세로 타일 하나      가로 타일 두 개
```

- 세로 타일 하나로 채웠다면, 남은 부분은 **가로 `n-1` 칸짜리 판**입니다.
- 가로 타일 두 개로 채웠다면, 남은 부분은 **가로 `n-2` 칸짜리 판**입니다.

맨 오른쪽 위 칸을 가로 타일로 덮으면 그 아래 칸도 가로 타일일 수밖에 없습니다. 세로 타일이 들어갈 자리가 없기 때문입니다.
그래서 두 경우를 더하면 됩니다.

```
tiling(n) = tiling(n-1) + tiling(n-2)
```

피보나치와 같은 식입니다. 시작값만 `tiling(0) = 1`, `tiling(1) = 1` 로 다릅니다.

</details>

<details>
<summary>힌트 2 — 2×2 타일이 있으면</summary>

맨 오른쪽이 채워지는 방법이 하나 더 생깁니다.

```
....X          ...YY          ...WW
....X          ...ZZ          ...WW

남은 판 n-1     남은 판 n-2     남은 판 n-2
```

```
tiling_with_square(n) = tiling_with_square(n-1) + 2 * tiling_with_square(n-2)
```

</details>

<details>
<summary>힌트 3 — C 로 표 채우기</summary>

`n` 의 최댓값이 정해져 있으니 `malloc` 없이 배열 크기를 정할 수 있습니다.

```c
long long dp[91];       /* dp[i] = 가로 i 칸짜리 판을 채우는 방법의 수 */
dp[0] = 1;
dp[1] = 1;
for (int i = 2; i <= n; i++)
    dp[i] = ...;
return dp[n];
```

배열에 손대기 **전에** `n` 이 범위 안인지 먼저 확인하세요.

</details>

## 자주 하는 실수

**`int` 로 계산하기**

`int a = 1, b = 1;` 처럼 두고 더하면 `tiling(50)` 이 음수로 나옵니다. 반환형만 `long long` 이고 중간 값이 `int` 여도 마찬가지입니다.

**범위를 확인하기 전에 배열 읽기**

`n = 100` 이나 `n = -1` 에서 `dp[n]` 을 읽으면 배열 밖입니다. 오류 없이 엉뚱한 값이 나오거나 프로그램이 죽습니다.

**`dp[0]` 을 `0` 으로 두기**

그러면 `dp[2] = dp[1] + dp[0] = 1` 이 되어 틀립니다. 빈 판을 채우는 방법은 **아무것도 놓지 않는 1가지**입니다.
