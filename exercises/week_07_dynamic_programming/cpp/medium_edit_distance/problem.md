## 편집 거리

한 단어를 다른 단어로 바꿀 때 아래 세 가지 작업을 쓸 수 있고, 각각 1번으로 셉니다.

| 작업 | 예 |
|---|---|
| 넣기 | `ct` → `cat` |
| 지우기 | `cart` → `cat` |
| 바꾸기 | `cut` → `cat` |

**편집 거리**는 `a` 를 `b` 로 바꾸는 데 필요한 **가장 적은 작업 횟수**입니다. `kitten` 을 `sitting` 으로 바꾸면 3번입니다.

```
kitten
sitten     k 를 s 로 바꾸기
sittin     e 를 i 로 바꾸기
sitting    끝에 g 넣기
```

| `a` | `b` | 편집 거리 | |
|---|---|---|---|
| `kitten` | `sitting` | `3` | |
| `horse` | `ros` | `3` | `h` 를 `r` 로 바꾸기, `r` 지우기, `e` 지우기 |
| `flaw` | `lawn` | `2` | 앞의 `f` 지우기, 끝에 `n` 넣기 |
| `data` | `date` | `1` | |
| `seuol` | `seoul` | `2` | 이웃한 두 글자의 자리를 바꾼 것도 2번입니다 |
| `""` (빈 문자열) | `abc` | `3` | 세 글자 넣기 |
| `abc` | `abc` | `0` | |

## 가장 가까운 단어

`closest_word` 는 사전(`dict`)의 단어 중 `word` 와 편집 거리가 가장 작은 단어의 **번호**를 반환합니다.

```
번호     0      1      2      3        4        5        6      7
dict     seoul  busan  daegu  incheon  gwangju  daejeon  ulsan  suwon
```

| `word` | 사전의 각 단어까지의 편집 거리 | 답 |
|---|---|---|
| `pusan` | 5, **1**, 5, 6, 6, 6, 2, 3 | `1` (busan) |
| `deajeon` | 6, 6, 4, 4, 6, **2**, 6, 5 | `5` (daejeon) |
| `seuol` | **2**, 5, 5, 6, 7, 5, 5, 3 | `0` (seoul) |

- 편집 거리가 같은 단어가 여럿이면 **번호가 가장 작은 단어**를 고릅니다.
- 사전이 비어 있으면(`n < 1`) `-1` 을 반환합니다.

<details>
<summary>힌트 1 — 표의 한 칸이 뜻하는 것</summary>

`dp[i][j]` 를 "**`a` 의 앞 `i` 글자**를 **`b` 의 앞 `j` 글자**로 바꾸는 가장 적은 횟수"라고 합시다.

- 표의 크기는 `(a 의 길이 + 1) × (b 의 길이 + 1)` 입니다. 0글자(빈 앞부분)도 있어야 하기 때문입니다.
- 답은 맨 오른쪽 아래 칸 `dp[a 의 길이][b 의 길이]` 입니다.

맨 위 줄과 맨 왼쪽 줄은 바로 채울 수 있습니다.

- `dp[i][0] = i` : `i` 글자를 빈 문자열로 만들려면 `i` 글자를 모두 지웁니다.
- `dp[0][j] = j` : 빈 문자열을 `j` 글자로 만들려면 `j` 글자를 모두 넣습니다.

</details>

<details>
<summary>힌트 2 — 나머지 칸 채우기</summary>

`a` 의 `i` 번째 글자는 `a[i-1]`, `b` 의 `j` 번째 글자는 `b[j-1]` 입니다. (`dp` 의 0번 칸이 빈 앞부분이라 한 칸씩 밀립니다.)

**두 글자가 같으면** 그 글자는 손댈 필요가 없습니다.

```
dp[i][j] = dp[i-1][j-1]
```

**다르면** 마지막 글자를 어떻게 맞출지 세 가지 중 가장 싼 것을 고르고 1번을 더합니다.

| 작업 | 남는 문제 |
|---|---|
| `a` 의 마지막 글자 지우기 | `dp[i-1][j]` |
| `b` 의 마지막 글자를 `a` 끝에 넣기 | `dp[i][j-1]` |
| `a` 의 마지막 글자를 `b` 의 마지막 글자로 바꾸기 | `dp[i-1][j-1]` |

```
dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
```

`horse` 와 `ros` 로 채운 표입니다. 각 칸은 왼쪽, 위, 왼쪽 위 칸만 보고 채웁니다.

```
          ""   r   o   s
     ""    0   1   2   3
     h     1   1   2   3
     o     2   2   1   2
     r     3   2   2   2
     s     4   3   3   2
     e     5   4   4   3     ← 답은 맨 오른쪽 아래의 3
```

</details>

## 자주 하는 실수

**표를 한 칸 작게 만들기**

`s.size() × t.size()` 로 만들면 빈 앞부분을 뜻하는 0번 줄이 없어서 첫 줄을 채울 수 없습니다. 둘 다 `+ 1` 입니다.

**글자 인덱스를 한 칸 밀리게 읽기**

`dp[i][j]` 를 채울 때 비교할 글자는 `a[i]`, `b[j]` 가 아니라 `a[i-1]`, `b[j-1]` 입니다.

**같은 글자일 때도 1을 더하기**

두 글자가 같으면 작업이 필요 없습니다. `dp[i-1][j-1]` 을 그대로 가져오세요.

**동점일 때 뒤 단어 고르기**

`closest_word` 에서 `if (d <= best)` 로 쓰면 거리가 같을 때 뒤 단어로 바뀝니다. `<` 를 쓰세요.
