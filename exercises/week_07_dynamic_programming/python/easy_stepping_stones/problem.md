# Week 07 / Python (쉬움) — 징검다리

개울에 돌이 `0` 번부터 `n` 번까지 한 줄로 놓여 있습니다. `0` 번 돌에서 출발해서 `n` 번 돌까지 건너려고 합니다.

- 한 번에 `jumps` 에 있는 칸 수만큼만 뛸 수 있습니다. `jumps = (1, 2)` 이면 한 칸이나 두 칸입니다.
- **부서진 돌**(`broken`)은 밟을 수 없습니다.
- 정확히 `n` 번 돌에 내려야 합니다. `n` 번을 넘어가는 점프는 할 수 없습니다.

**(a)** 건너는 방법이 몇 가지인지, **(b)** 밟는 돌의 비용을 가장 적게 내려면 얼마인지 구하세요.

## (a) `count_ways` — 건너는 방법의 수

`n = 4`, `jumps = (1, 2)` 이면 5가지입니다.

```
0 → 1 → 2 → 3 → 4
0 → 1 → 2 → 4
0 → 1 → 3 → 4
0 → 2 → 3 → 4
0 → 2 → 4
```

밟는 순서가 다르면 다른 방법으로 셉니다. `2` 번 돌이 부서져 있으면(`broken = {2}`) `0 → 1 → 3 → 4` 한 가지만 남습니다.

| `n` | `jumps` | `broken` | 답 | |
|---|---|---|---|---|
| `4` | `(1, 2)` | | `5` | |
| `4` | `(1, 2)` | `{2}` | `1` | |
| `5` | `(1, 3)` | | `4` | |
| `10` | `(1, 2, 3)` | | `274` | |
| `5` | `(2,)` | | `0` | 두 칸씩만 뛰면 홀수 번 돌에 닿을 수 없습니다 |
| `7` | `(1, 2)` | `{3, 4}` | `0` | 부서진 돌 두 개를 한 번에 넘을 수 없습니다 |
| `0` | `(1, 2)` | | `1` | 이미 도착해 있습니다. 아무것도 안 하는 한 가지입니다 |

## (b) `min_cost` — 가장 적은 비용

이번에는 돌마다 밟을 때 내는 비용이 있습니다. `cost[i]` 가 `i` 번 돌의 비용이고, **마지막 돌**(`len(cost) - 1` 번)이 도착점입니다.

- 돌을 밟을 때마다 그 돌의 비용을 냅니다. 도착하는 마지막 돌의 비용도 냅니다.
- 출발하는 `0` 번 돌은 이미 서 있으니 내지 않습니다.
- 도착할 수 없으면 `-1` 을 반환합니다.

`cost = [0, 5, 1, 7, 2]`, `jumps = (1, 2)` 이면 답은 `3` 입니다. `0 → 2 → 4` 로 가면 `1 + 2 = 3` 입니다.
`2` 번 돌이 부서져 있으면 `0 → 1 → 3 → 4` 밖에 없어서 `5 + 7 + 2 = 14` 입니다.

| `cost` | `jumps` | `broken` | 답 | |
|---|---|---|---|---|
| `[0, 5, 1, 7, 2]` | `(1, 2)` | | `3` | `0 → 2 → 4` |
| `[0, 5, 1, 7, 2]` | `(1, 2)` | `{2}` | `14` | `0 → 1 → 3 → 4` |
| `[0, 10, 1, 1, 10, 1]` | `(1, 2, 3)` | | `2` | `0 → 2 → 5` 또는 `0 → 3 → 5` |
| `[0, 3, 2, 4]` | `(2,)` | | `-1` | `3` 번 돌에 닿을 수 없습니다 |
| `[0]` | `(1,)` | | `0` | 출발점이 곧 도착점입니다 |

## 구현할 함수

`solution.py` 에 작성하세요.

```python
def count_ways(n: int, jumps: Sequence[int], broken: Collection[int] = ()) -> int: ...
def min_cost(cost: Sequence[int], jumps: Sequence[int], broken: Collection[int] = ()) -> int: ...
```

`broken` 을 주지 않으면 부서진 돌이 없는 것입니다.

## 입력 조건

- `jumps` 에는 1 이상의 서로 다른 정수가 하나 이상 들어 있습니다. 순서는 정해져 있지 않습니다.
- `n` 과 `len(cost)` 는 300 이하입니다. `cost` 의 각 값은 0 이상입니다.
- `broken` 에는 출발점(`0`)과 도착점이 들어 있지 않습니다. 리스트로 올 수도, 집합으로 올 수도 있습니다.

## 지켜야 할 것

- **돌 300개짜리 입력도 2초 안에 끝나야 합니다.** 모든 경로를 하나씩 따라가면 경로가 10⁶² 개가 넘어서 끝나지 않습니다.
  돌마다 답을 한 번씩만 구하세요.
- 입력(`cost`, `jumps`, `broken`)을 바꾸지 마세요.

<details>
<summary>힌트 1 — i 번 돌에 오기 직전에는 어디 있었을까요</summary>

`ways[i]` 를 "`0` 번에서 `i` 번 돌까지 오는 방법의 수"라고 합시다.

`jumps = (1, 2)` 이면 `i` 번 돌에 내리기 직전에는 `i - 1` 번이나 `i - 2` 번 돌에 있었습니다.
그래서 두 돌까지 오는 방법의 수를 더하면 됩니다. 피보나치와 같은 모양입니다.

```
ways[i] = ways[i - 1] + ways[i - 2]
```

`jumps` 가 다르면 `jumps` 의 모든 `j` 에 대해 `ways[i - j]` 를 더합니다. 부서진 돌은 도착할 수 없으니 `ways` 가 `0` 입니다.

```
돌        0   1   2   3   4         n = 4, jumps = (1, 2), broken = {2}
부서짐            X
ways      1   1   0   1   1
```

`ways[3] = ways[2] + ways[1] = 0 + 1`, `ways[4] = ways[3] + ways[2] = 1 + 0` 입니다.

</details>

<details>
<summary>힌트 2 — 최솟값은 더하기 대신 min</summary>

`best[i]` 를 "`i` 번 돌까지 오는 데 드는 가장 적은 비용"이라고 하면 힌트 1과 같은 모양이 됩니다.

```
best[i] = min(best[i - j] for j in jumps) + cost[i]
```

아직 갈 수 없는 돌은 `float("inf")` 로 두면 `min` 이 알아서 피해 갑니다.

```
돌        0   1   2   3   4         cost = [0, 5, 1, 7, 2], jumps = (1, 2)
cost      0   5   1   7   2
best      0   5   1   8   3
```

마지막에 `best` 가 여전히 `inf` 이면 `-1` 을 반환하세요.

</details>

<summary>힌트 3 — 재귀로 풀고 싶다면</summary>

피보나치 문제의 `fib_memo` 처럼 풀어도 됩니다. "`i` 번 돌에서 도착점까지 가는 방법의 수"를 구하는 재귀를 만들고,
dict 에 돌 번호별로 답을 적어 두면 됩니다. 돌이 300개여도 재귀 깊이는 300 이하라서 괜찮습니다.

## 자주 하는 실수

**음수 인덱스로 리스트 읽기**

`i - j` 가 음수인데 `ways[i - j]` 를 읽으면 파이썬은 오류를 내지 않습니다. **리스트 뒤에서부터** 읽습니다.
`ways[-1]` 은 마지막 칸입니다. 답이 조용히 틀리니 `i - j >= 0` 인지 꼭 확인하세요.

**갈 수 없는 돌을 0 으로 두기**

최솟값을 구할 때 갈 수 없는 돌의 `best` 를 `0` 으로 두면, 그 돌을 거쳐 가는 것이 **공짜**로 계산됩니다.
`float("inf")` 로 두세요.

**`inf` 를 그대로 반환하기**

도착할 수 없을 때는 `-1` 입니다.
