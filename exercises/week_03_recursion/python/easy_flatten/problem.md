# Week 03 / Python (쉬움) — 중첩 리스트 펼치기

리스트 안에 리스트가 들어 있고, 그 안에 또 리스트가 있을 수 있습니다.
이것을 평평하게 펴는 함수와, 얼마나 깊이 중첩되었는지 세는 함수를 만듭니다.

```python
flatten([1, [2, [3, [4]]]])   # [1, 2, 3, 4]
depth([1, [2, [3, [4]]]])     # 4
```

구조 자체가 재귀적이라서, 재귀를 쓰기에 가장 자연스러운 문제입니다.

## 구현할 함수

```python
def flatten(nested: list) -> list[int]: ...
def depth(nested: list) -> int: ...
```

| 함수 | 하는 일 |
|---|---|
| `flatten` | 모든 정수를 **원래 순서대로** 한 줄로 펴서 반환 |
| `depth` | 리스트가 몇 겹으로 쌓여 있는지 |

## 조건

- 입력의 원소는 **정수이거나 리스트**입니다. 다른 타입은 들어오지 않습니다.
- 중첩 깊이에 제한이 없습니다. 몇 겹이든 처리해야 합니다.
- 바깥 리스트 자체가 한 겹입니다. `depth([])` 와 `depth([1, 2])` 는 모두 `1` 입니다.
- 빈 리스트도 한 겹으로 셉니다. `depth([[], []])` 는 `2` 입니다.
- `flatten` 은 새 리스트를 반환합니다. 입력을 바꾸지 마세요.
- 반복문으로 직접 스택을 만들어 풀지 마세요. 이번 주 주제는 재귀입니다.

## 예시 몇 개 더

```python
flatten([])                 # []
flatten([[], [[]]])         # []
flatten([[1, 2], [3], 4])   # [1, 2, 3, 4]

depth([1, 2])               # 1
depth([1, [2]])             # 2
depth([[1], [[2]]])         # 3
```

`depth` 에서 헷갈리기 쉬운 부분이 있습니다. `[[1], [[2]]]` 는 가지마다 깊이가 다릅니다.
왼쪽은 2겹, 오른쪽은 3겹이죠. **가장 깊은 쪽**을 답으로 합니다.
