# Week 03 / C (쉬움) — 하노이 탑

원반 `n` 개가 1번 기둥에 크기 순으로 쌓여 있습니다. 이것을 3번 기둥으로 옮기는
**가장 짧은 이동 순서**를 만들어 주세요. 기둥은 1, 2, 3 세 개입니다.

규칙은 두 가지입니다.

- 한 번에 원반 하나만, 기둥 맨 위에서 뽑아 다른 기둥 맨 위에 올립니다.
- 큰 원반을 작은 원반 위에 올릴 수 없습니다.

```
n = 1   ->  1수:  1->3
n = 2   ->  3수:  1->2, 1->3, 2->3
n = 3   ->  7수:  1->3, 1->2, 3->2, 1->3, 2->1, 2->3, 1->3
```

## 시그니처

```c
int hanoi_count(int n);
int hanoi_moves(int n, int *out, int out_capacity);
```

| 함수 | 하는 일 | 반환값 |
|---|---|---|
| `hanoi_count` | 최소 이동 횟수 | 그 횟수, `n` 이 범위 밖이면 `-1` |
| `hanoi_moves` | 이동 순서를 `out` 에 | **이동 횟수**, 범위 밖이거나 용량 부족이면 `-1` |

`hanoi_moves` 는 한 번의 이동마다 **정수 두 개**(출발 기둥, 도착 기둥)를 씁니다.
이동이 7번이면 `out` 에 14개가 들어가고, 반환값은 `7` 입니다.

```
n = 2  ->  out = [1,2, 1,3, 2,3],  반환값 3
```

## 조건

- `n` 은 `0` 이상 `31` 이하입니다. 범위를 벗어나면 `-1` 을 반환합니다.
  (`31` 이 상한인 이유는 `2^31 - 1` 이 `int` 에 담기는 마지막 값이기 때문입니다.)
- `n = 0` 이면 이동이 없습니다. `hanoi_count(0)` 은 `0`, `hanoi_moves` 도 `0` 을 반환합니다.
- 최소 이동 순서는 **단 하나뿐**입니다. 그래서 채점기가 순서를 그대로 비교합니다.
- 반복문으로 풀지 마세요. 이번 주 주제는 재귀입니다.

## 힌트

원반 `n` 개를 1번에서 3번으로 옮기는 일은 세 단계로 쪼갤 수 있습니다.

```
1. 위쪽 n-1 개를  1번 -> 2번   (3번을 임시 기둥으로 씀)
2. 가장 큰 원반을  1번 -> 3번
3. 그 n-1 개를    2번 -> 3번   (1번을 임시 기둥으로 씀)
```

1단계와 3단계가 **같은 문제의 작은 판**입니다. 원반 개수가 하나 줄고 기둥 번호만 바뀌었죠.
그래서 "몇 개를, 어디서, 어디로, 어디를 임시로" 네 가지를 받는 보조 함수를 하나 두면 편합니다.

```c
static void solve(int n, int from, int to, int via, ...);
```
