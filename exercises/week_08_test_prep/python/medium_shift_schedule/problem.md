# Week 08 / Python (중간) — 아르바이트 일정

앞으로 `n` 일 동안 아르바이트를 고를 수 있습니다. `pay[i]` 는 `i` 일에 일하면 받는 돈입니다.
몸이 버티지 못해서 **사흘을 연달아 일할 수는 없습니다.** 이틀까지는 연달아 일해도 됩니다.

**(a)** 벌 수 있는 가장 많은 돈과, **(b)** 그만큼 벌려면 어느 날 일해야 하는지 구하세요.

## 예시

`pay = [3, 2, 5, 10, 7]` 이면 답은 `22` 입니다.

```
날        0    1    2    3    4
pay       3    2    5   10    7
일함      O    O    X    O    O       3 + 2 + 10 + 7 = 22
```

이틀 일하고 하루 쉬고 다시 이틀 일했습니다. 하루씩 걸러 일하면(`0, 2, 4` 일) `3 + 5 + 7 = 15` 밖에 못 법니다.

| `pay` | (a) `max_pay` | (b) `work_days` | |
|---|---|---|---|
| `[3, 2, 5, 10, 7]` | `22` | `[0, 1, 3, 4]` | |
| `[1, 2, 3]` | `5` | `[1, 2]` | 사흘 다는 못 하니 가장 싼 날을 쉽니다 |
| `[10, 10, 1, 10, 10]` | `40` | `[0, 1, 3, 4]` | |
| `[5, 5, 5, 5]` | `15` | `[0, 1, 3]` 등 | 답이 여럿입니다 |
| `[]` | `0` | `[]` | |

## 구현할 함수

`solution.py` 에 작성하세요.

```python
def max_pay(pay: Sequence[int]) -> int: ...
def work_days(pay: Sequence[int]) -> list[int]: ...
```

- `work_days` 는 일하는 날의 번호를 **오름차순** 리스트로 반환합니다.
- 가장 많이 버는 일정이 여럿이면 **아무거나** 하나 반환하면 됩니다. 채점기는 반환한 일정을 직접 확인합니다.
  날 번호가 겹치지 않고 오름차순인지, 사흘 연속이 없는지, 번 돈이 `max_pay` 와 같은지 봅니다.

## 입력 조건

- `pay` 의 길이는 0 이상 500 이하, 각 값은 0 이상입니다.

## 지켜야 할 것

- **500일짜리 입력도 2초 안에 끝나야 합니다.** 가능한 일정을 모두 따져 보면 2⁵⁰⁰ 가지라서 끝나지 않습니다.
- `pay` 를 바꾸지 마세요.

막힐 때 하나씩 펼쳐 보세요.

<details>
<summary>힌트 1 — 마지막 날을 어떻게 보냈나</summary>

`best[i]` 를 "**앞의 `i` 일**만 놓고 벌 수 있는 가장 많은 돈"이라고 합시다. 답은 `best[n]` 입니다.

`i - 1` 일(앞의 `i` 일 중 마지막 날)을 어떻게 보냈는지는 세 가지뿐입니다.

| 마지막 날 | 그 앞 | 버는 돈 |
|---|---|---|
| 쉼 | 상관없음 | `best[i-1]` |
| 일함 | `i-2` 일은 쉼 | `pay[i-1] + best[i-2]` |
| 일함 | `i-2` 일도 일함, `i-3` 일은 쉼 | `pay[i-1] + pay[i-2] + best[i-3]` |

셋 중 가장 큰 값이 `best[i]` 입니다. 세 번째 경우에서 `i-3` 일을 쉬게 했기 때문에 사흘 연속이 생기지 않습니다.

</details>

<details>
<summary>힌트 2 — 예시로 채운 표</summary>

```
i          0    1    2    3    4    5
pay[i-1]        3    2    5   10    7
best[i]    0    3    5    8   18   22
```

`best[5] = max(18, 7 + best[3], 7 + 10 + best[2]) = max(18, 15, 22) = 22` 입니다.

`i` 가 1, 2 일 때는 `best[i-2]`, `best[i-3]` 이 없습니다. 그 경우는 `0` 으로 치거나 아예 빼세요.

</details>

<details>
<summary>힌트 3 — 어느 날 일했는지 되짚기</summary>

표를 다 채운 뒤 `i = n` 에서 거꾸로 내려옵니다. `best[i]` 가 힌트 1의 세 경우 중 **어느 것과 같은지** 보면 됩니다.

- `best[i-1]` 과 같으면 `i-1` 일은 쉬었습니다. `i` 를 1 줄입니다.
- `pay[i-1] + best[i-2]` 와 같으면 `i-1` 일에 일했습니다. 적고 `i` 를 2 줄입니다.
- 아니면 `i-1`, `i-2` 일에 일했습니다. 둘 다 적고 `i` 를 3 줄입니다.

뒤에서부터 찾았으니 마지막에 뒤집어서 오름차순으로 만드세요. Week 07 배낭 문제의 `knapsack_choose` 와 같은 방법입니다.

</details>

## 자주 하는 실수

**하루씩 걸러 일하기만 따지기**

"이웃한 날은 둘 중 하나만"이라고 생각하면 이틀 연속 일하는 경우를 빠뜨립니다. 예시에서 `15` 가 나오면 이 실수입니다.

**음수 인덱스로 리스트 읽기**

`i = 1` 일 때 `best[i - 3]` 은 `best[-2]` 이고, 파이썬은 오류 없이 **뒤에서 두 번째 칸**을 읽습니다.
답이 조용히 틀리니 `i - 3 >= 0` 인지 먼저 확인하세요.

**되짚은 날을 뒤집지 않기**

뒤에서부터 찾으면 날짜가 내림차순으로 나옵니다.
