# Week 01 / Python (중간) — 사이클 탐지 (플로이드)

연결 리스트의 마지막 노드가 앞쪽 노드를 가리켜 고리가 생길 수 있다.
사이클이 **시작되는 노드**와 사이클의 **길이**를 찾는다.

```
1 -> 2 -> 3 -> 4
          ^         |
          +---------+

detect_cycle(head)  ->  값이 3인 노드
cycle_length(head)  ->  2   (3 -> 4 -> 3)
```

## 구현할 함수

```python
def detect_cycle(head: Node | None) -> Node | None: ...  # 사이클 시작 노드, 없으면 None
def cycle_length(head: Node | None) -> int: ...          # 사이클 길이, 없으면 0
```

## 조건

- **추가 메모리는 상수만 쓴다.** 방문한 노드를 `set` 이나 `dict` 에 모으는 풀이는 답으로 치지 않는다.
  토끼와 거북이(느린 포인터 / 빠른 포인터)로 푼다.
- 반환하는 것은 값이 아니라 **노드 객체 그 자체**다. 채점기가 `is` 로 확인한다.
- 사이클이 리스트 전체를 감쌀 수도 있고(머리가 곧 시작점), 노드 하나가 자기 자신을 가리킬 수도 있다.
